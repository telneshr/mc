# mc.telnes.de

The page for the telnes Minecraft server at [mc.telnes.de](https://mc.telnes.de). Plain HTML, hosted with GitHub Pages.

The live status comes from the free [mcsrvstat.us](https://mcsrvstat.us) service, called from the visitor's browser.
Fonts: Hanken Grotesk (SIL Open Font License, see `fonts/`), stored here. The logo is Dancing Script Bold (SIL OFL) converted to outlines.
